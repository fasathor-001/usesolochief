# Support

## Contact

**Email:** fasathor@icloud.com  
**Subject prefix:** `[SoloChief Support] <brief description>`

For security vulnerabilities, see [SECURITY.md](SECURITY.md) instead.

## Response Expectations

| Issue type          | Target first response |
|---------------------|-----------------------|
| Bug report          | 48 hours              |
| Billing question    | 48 hours              |
| Feature request     | 5 business days       |
| Security issue      | 48 hours (via SECURITY.md contact) |

SoloChief is currently in early access. Response times may be longer during heavy development
periods. We will always acknowledge receipt of a support request.

## What to Include in a Bug Report

Please provide the following so we can reproduce and fix the issue quickly:

```
Subject: [SoloChief Support] Bug — <one-line description>

**What happened:**
A clear description of what you observed.

**What you expected:**
What you expected to happen instead.

**Steps to reproduce:**
1. Go to ...
2. Click ...
3. See error

**Browser and OS:**
e.g. Chrome 126 on macOS 14.5

**Screenshot or recording:**
Attach if possible — especially for visual or layout issues.

**Account email:**
The email address you use to log in (never send passwords).

**Error message (if any):**
Copy the exact text of any error shown on screen.
```

## Compliance Document Extraction Issues

If you use SoloChief to export data (e.g. weekly review PDFs or commitment exports) and the
extracted content is incorrect, missing, or improperly formatted, please report it with:

- The type of export (weekly review, commitment list, etc.)
- The date the export was generated
- A description of what is wrong (missing data, wrong dates, garbled text, etc.)
- Whether the data is correct inside the app but wrong in the export

Exported documents are static snapshots — see [PDF_COMPLIANCE.md](PDF_COMPLIANCE.md) for
details on why old exports cannot be automatically updated.

## Billing Support

SoloChief uses [Polar](https://polar.sh) for subscription management. For billing questions:

- **To cancel or change your plan:** log in at polar.sh and manage your subscription directly.
- **For refund requests:** email the support address above with your account email and the
  date of the charge.
- **For invoice copies:** these are issued automatically by Polar — check your inbox for
  emails from Polar.

Billing support is handled by the same support email during Phase 1. When the user base grows,
billing support may be separated into a dedicated channel — this file will be updated accordingly.

## Feature Requests

Feature requests are welcome. Email the support address with:

- What you want to do that you cannot currently do
- How often you need it
- Whether it is blocking you from using the product

We do not commit to timelines for feature requests, but all requests are read and considered
for the roadmap.

## What We Cannot Help With

- Recovering data deleted by the user (hard deletes are permanent)
- Providing access to another user's account
- Bypassing subscription requirements
